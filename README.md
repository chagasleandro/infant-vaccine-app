# 🧒 Infant Vaccination App

An infant vaccination app built with **React Native**, designed to help parents keep track of their child's vaccine schedule, doctor appointments, and health reminders.

![App Screenshot](./screenshot.png)

## 📱 Features

- 🍼 **Child Profile**: Register and manage your child's data.
- 💉 **Vaccine Schedule**: View vaccine history and upcoming vaccines.
- 👩‍⚕️ **Doctors & Appointments**: Find pediatricians and book consultations.
- ⏰ **Reminders**: Stay updated with upcoming vaccines and appointments.

---

## 🚀 Getting Started

Follow the steps below to run the project locally.

### 📦 Prerequisites

- Node.js >= 16.x
- Expo CLI (or React Native CLI)
- Git
- Android Studio or Xcode (for device emulator)

### 📥 Clone the repository

```bash
git clone https://github.com/seu-usuario/infant-vaccine-app.git
cd infant-vaccine-app

📦 Install dependencies
npm install

▶️ Run the app

Using Expo:
npx expo start

Or using React Native CLI:
npx react-native run-android
# or
npx react-native run-ios
